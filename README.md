# Portafolio de Roberto Mendoza

Sitio personal: **https://roberto-mendoza.vercel.app**

Hecho con Astro, Tailwind CSS, GSAP y Lenis. Todo el contenido (textos, proyectos, habilidades) está en `src/datos.js`.

## Comandos

| Comando           | Qué hace                                        |
| :---------------- | :---------------------------------------------- |
| `npm install`     | Instala las dependencias                        |
| `npm run dev`     | Abre el sitio en `localhost:4321` para trabajar |
| `npm run build`   | Genera el sitio final en `./dist/`              |
| `npm run preview` | Muestra ese sitio final antes de publicarlo     |

## Publicar

El repositorio está conectado a Vercel: cada `git push` a `main` publica el sitio solo.
